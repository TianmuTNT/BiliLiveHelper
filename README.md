# BiliLiveHelper
B站直播小助手，自动进行多项优化，提升观看体验！

## 优化列表
- 自动移除直播中的模糊遮罩
- 自动移除直播中B站图标
- 自动移除直播中的公告弹幕
- 防后台画质降级
